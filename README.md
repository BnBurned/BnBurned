## 🧊 Hakkımda

Minecraft ekosisteminde bağımsız çalışan bir modder ve server developer'ım. Fabric modlarından cubiomes tabanlı seed arama araçlarına, Folia/Velocity server mimarisinden gerçek zamanlı ses transkripsiyon araçlarına kadar geniş bir yelpazede projeler yürütüyorum.

<br>

## 🔥 Şu An Neyle Uğraşıyorum

<table width="100%">
<tr>
<td width="33%" align="center">

**🌱 Speedrun Seed Finder**
<br>
1.16.1 için Python + C (cubiomes) hibrit tool. Tkinter GUI, precompiled DLL/SO desteği, multiprocessing, resume'lu NDJSON çıktısı.

</td>
<td width="33%" align="center">

**🎙️ Real-Time Transcription**
<br>
WASAPI loopback ile sistem sesini yakalayan, faster-whisper (CPU) kullanan, F2/F9 global hotkey'li tkinter uygulaması.

</td>
<td width="33%" align="center">

**🏝️ KIZILMC**
<br>
Folia 1.21.11 + Velocity tabanlı SkyBlock sunucusu. ~50 plugin'lik liste ve otomatik kurulum script'leri.

</td>
